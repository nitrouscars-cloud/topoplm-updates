# TopoPLM pour Windows

[Télécharger la dernière version](https://github.com/nitrouscars-cloud/topoplm-updates/releases/latest/download/TopoPLM-win-x64.zip)

1. Enregistrez votre chantier et fermez l’ancienne version.
2. Extrayez tout le ZIP dans un dossier personnel.
3. Ouvrez **TopoPLM.exe** dans ce dossier.

Les mises à jour suivantes se lancent depuis **Mises à jour** dans TopoPLM. Aucun compte ni jeton n’est nécessaire.

Ce dépôt distribue uniquement le programme compilé et son assemblage pour Windows 64 bits. Les relevés clients et le code source de l’application restent privés. Les licences des composants tiers sont incluses dans le téléchargement.
